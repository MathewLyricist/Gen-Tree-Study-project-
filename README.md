# Gen Tree Study project
Учебный проект, целью которого являлась разработка экспертной системы с индивидуальной идеей реализации генетического кода.

Симулятор Эволюции — это десктопное приложение на Java Swing, которое моделирует популяцию людей с генетическими признаками, процессом размножения, естественным отбором и визуализацией генеалогического древа. Программа позволяет наблюдать за эволюцией в реальном времени, настраивать параметры симуляции и изучать детали каждой особи.

Возможности
- Генетика и наследование: каждый человек обладает набором признаков (рост, вес, цвет глаз, волос, мускулатура и др.), которые наследуются от родителей с возможными мутациями.
- Естественный отбор: приспособленность (fitness) рассчитывается на основе ИМТ, мускулатуры и возраста. Особей с низкой приспособленностью и пожилых отсеивают при превышении лимита популяции.
- Размножение: пары формируются случайно, количество детей зависит от фертильности (возраста) и заданного максимума.

Визуализация:

- Таблица текущей популяции с сортировкой, цветовой индикацией и статистикой.
- Детальная карточка особи с отображением всех признаков, ИМТ, статуса и генеалогической информации.
- Интерактивное генеалогическое дерево с масштабированием, перетаскиванием и фильтрацией.
- Отдельное диалоговое окно для полного семейного дерева выбранной особи.
Управление:
- Запуск/остановка эволюции, пошаговое выполнение, сброс симуляции.
- Добавление основателей (случайных или кастомных с настройкой признаков).
- Настройка максимального размера популяции, количества детей на пару, размера пула потоков.
- Производительность: используется многопоточность (ExecutorService, параллельные потоки) для ускорения расчётов при большой популяции.
- Сохранение изображений: при отсутствии файлов man.jpeg и woman.jpeg создаются заглушки.

Технологии
Java 21 (используются switch-выражения, Math.clamp, record-подобные конструкции, потоки)
Swing для графического интерфейса
Многопоточность (ExecutorService, CompletableFuture, CopyOnWriteArrayList)
Java 2D для отрисовки дерева

Установка и запуск
Требования: JDK 21 или выше (проверьте: java -version);
Операционная система: Windows, Linux, macOS.

Дополнительные файлы (опционально)
Поместите изображения man.jpeg и woman.jpeg в рабочую директорию для отображения портретов. Если их нет, программа сгенерирует заглушки.

Использование
Добавьте основателей: выберите тип в выпадающем списке и нажмите «Добавить выбранного» или создайте кастомного основателя с помощью диалога.
Настройте параметры: укажите количество лет эволюции, максимальную популяцию, число основателей, максимальное число детей на пару.
Запустите эволюцию: нажмите «▶ Запустить эволюцию» или выполняйте по одному году кнопкой «⏭ Один год».
Наблюдайте: следите за таблицей популяции, выбирайте особей для просмотра деталей. Используйте вкладку с деревом для навигации (масштаб, перемещение).
Анализируйте: в панели деталей отображаются генетические признаки, генеалогия, семейное дерево.

Структура проекта

├── ControlPanel.java         // Панель управления
├── DetailsPanel.java         // Панель деталей выбранной особи
├── PopulationPanel.java      // Таблица популяции и статистика
├── GenealogyTreePanel.java   // Интерактивное дерево всех особей
├── FamilyTreeDialog.java     // Диалог полного семейного дерева
└── (опционально) man.jpeg, woman.jpeg
